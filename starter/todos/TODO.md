# TODO

The to-do list across all projects, owned by `todos/`; every session adds and ticks off its items here (rule W3).
One line per item, details stay in the project folder.

Format: `- [ ] **What** — short context → detail file (added YYYY-MM-DD)`. Done: tick `[x]` and add
`(done YYYY-MM-DD)`; remove ticked items after ~2 weeks. Recurring tasks are chores (`<project>/chores.md`).
Sections: `## <project path>` (relative to the workspace), plus `## Priority` (urgent, any project) and
`## Questions from agents`: unattended jobs (C4) that need the user add
`- [ ] **Question?** — context (from <project>/jobs/<name>, asked YYYY-MM-DD)`; the answer is appended as `answer: …`.
